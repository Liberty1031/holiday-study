2026.3.11常用格式符
修饰符示例	           含义	                                示例效果
%5d	    整数占 5 个字符宽度，右对齐（不足补空格）	printf("%5d", 123) →   123
%-5d	整数占 5 个字符宽度，左对齐（不足补空格）	printf("%-5d", 123) → 123  
%05d	整数占 5 个字符宽度，不足补 0	            printf("%05d", 123) → 00123
%8.2f	浮点数总宽度 8（含小数点）+ 保留 2 位小数	printf("%8.2f", 3.14) →     3.14

格式符	适用场景	           核心含义	示例（printf）	输出 / 输入效果
整数类				
%d	int 类型（十进制）	输出 / 读取十进制整数（最常用）              	printf("%d", 123)   输出：123

%u	unsigned int 类型	无符号十进制整数（只存正数，范围更大）	        printf("%u", -1)	输出：4294967295（无符号下 - 1 的表示）
%o	整数（八进制）	    输出 / 读取八进制整数（无前导 0）	            printf("%o", 8)	    输出：10（8 的八进制是 10）
%x	整数（十六进制）	小写十六进制（无前导 0x）	printf("%x", 15)	                    输出：f
%X	整数（十六进制）	大写十六进制	                                printf("%X", 15)    输出：F
浮点数类				
%f	float/double 类型	十进制浮点数（默认保留 6 位小数）	printf("%f", 3.14)	输出：3.140000
%lf	double 类型（仅 scanf）	scanf 中读取 double，printf 中等同于 % f	scanf("%lf", &num)	读取 double 类型变量
%.2f	float/double 类型	保留 2 位小数（四舍五入）	printf("%.2f", 3.1415)	输出：3.14
%e	浮点数（科学计数法）	小写 e 表示指数	printf("%e", 123.45)	输出：1.234500e+02
%E	浮点数（科学计数法）	大写 E 表示指数	printf("%E", 123.45)	输出：1.234500E+02
%g	浮点数（自动精简）	自动选择 % f 或 % e，去掉无意义的 0	printf("%g", 3.14000)	输出：3.14
字符 / 字符串类

指针
1.官方定义
指针是 C 语言中的一种特殊变量，它存储的不是普通的数值（如 10、20），而是另一个变量在内存中的地址（可以理解为变量的 “内存门牌号”）。
2.
操作	   符号	   含义
声明指针	*	  int *p; → 声明一个指向int类型变量的指针（p是指针变量名）；
取变量地址	&	  &a → 获取变量a的内存地址（比如 0x0061FF1C）；
解引用指针	*	  *p → 根据指针p存储的地址，访问 / 修改对应地址里的变量值（“打开储物柜”）。

定义函数
一、完整结构：
返回值类型 函数名(参数类型1 参数名1, 参数类型2 参数名2, ...) {
    // 函数体：要执行的代码逻辑（比如计算、输出、循环等）
    [return 返回值;] // 无返回值时，这行省略，且返回值类型写void
}
二、定义函数的常见类型
1.无参数、无返回值（只执行操作，比如打印）
// 定义：打印欢迎语，无输入、无输出
void print_welcome(void) { // void表示无返回值，(void)表示无参数
    printf("欢迎学习C语言函数！\n");
    // 无return语句（void类型不需要）
}
// 调用（在main中使用这个函数）
int main() {
    print_welcome(); // 直接写函数名+()即可调用
    return 0;
}
2.有参数、有返回值（核心场景，比如求和）
// 定义：求两个整数的和，输入2个int，返回int结果
int get_sum(int a, int b) { // 参数：2个int型输入；返回值：int型
    int sum = a + b; // 函数体：计算求和
    return sum;      // 返回计算结果（类型和int匹配）
}

// 调用
int main() {
    int x = 5, y = 3;
    // 调用函数，接收返回值
    int result = get_sum(x, y); 
    printf("和为：%d\n", result); // 输出8
    return 0;
}
3.无参数、有返回值（比如获取固定值）
// 定义：返回圆周率（简化版），无输入，返回float
float get_pi(void) {
    return 3.14159; // 返回浮点型结果
}

// 调用
int main() {
    float pi = get_pi();
    printf("圆周率：%.2f\n", pi); // 输出3.14
    return 0;
}
4.有参数、无返回值（比如打印指定次数的内容）
// 定义：打印n次“Hello”，输入int型次数，无输出
void print_hello(int n) {
    for (int i = 0; i < n; i++) {
        printf("Hello\n");
    }
}

// 调用
int main() {
    print_hello(2); // 输入参数2，打印2次Hello
    return 0;
}

头文件include<math.h>的调用
1>.#include <math.h> 是 C 语言的预处理指令，作用是：
把 C 语言标准库中名为 math.h 的「数学头文件」里的内容，“复制粘贴” 到当前代码的这个位置，让编译器能识别并使用头文件中声明的数学运算函数（比如开平方、求次方、三角函数等）。
2>.math.h 里常用的数学函数
函数名	       功能	             示例	         结果
sqrt(x)	  计算 x 的平方根	    sqrt(36)	     6.0
pow(x,y)  计算 x 的 y 次方	    pow(2,3)	     8.0
fabs(x)	  计算浮点数的绝对值	fabs(-3.5)	     3.5 
sin(x)	  正弦函数（x 是弧度）	sin(3.14159/2)	 1.0
cos(x)	  余弦函数（x 是弧度）	cos(3.14159)	-1.0
3>.函数参数类型：
math.h 中的函数大多要求参数是 double 类型（比如 sqrt(5) 会自动转 sqrt(5.0)，但建议显式写 sqrt(5.0) 更规范）
